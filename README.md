## English

### 🐾 What is Mewhagram?
**Mewhagram** is a custom open-source modification based on [Telegram-FOSS](https://github.com/Telegram-FOSS/Telegram-FOSS). It is designed to be lightweight, tracker-free, and equipped with quality-of-life privacy and styling features.

### ✨ Key Features:
- ⏱️ **Exact Timestamp with Seconds (`HH:mm:ss`)**: View exact send times for messages and precise Last Seen status (even for users with Telegram Premium).
- ⭐ **Local Telegram Premium**: Client-side premium unlock (premium star icon, custom emoji reactions, expanded UI limits).
- 🎨 **Custom Mewha Themes**: Unique pink/purple accent palettes and dynamic UI customization.
- 🛡️ **Pure FOSS**: Fully de-googled, free of Google Play Services and telemetry.

## 简体中文

### 🐾 什么是 Mewhagram？
**Mewhagram** 是基于开源 [Telegram-FOSS](https://github.com/Telegram-FOSS/Telegram-FOSS) 开发的自定义修改版客户端。完全去除谷歌服务（GMS）和追踪器，提供更高的隐私性和个性化定制功能。

### ✨ 核心功能：
- ⏱️ **精确到秒的时间戳（`时:分:秒` / `HH:mm:ss`）**：在消息发送时间和最后上线状态中精确显示到秒（包括 Telegram Premium 用户）。
- ⭐ **本地 Telegram Premium（假大会员）**：客户端本地解锁高级功能（专属高级图标、自定义表情反应、解除界面限制）。
- 🎨 **Mewha 个性化主题**：粉色/紫色专属强调色与界面定制。
- 🛡️ **纯粹开源（FOSS）**：完全脱离谷歌生态，无任何后台数据收集。
